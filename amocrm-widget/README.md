# Виджет amoCRM — «Сверка планов БТИ»

Модуль загружает две схемы помещения (план БТИ и вашу схему) и автоматически
определяет, совпадают ли планировки. Тяжёлая логика вынесена в размещённое
веб‑приложение (`/bti`) и его бэкенд (`/api/bti/compare`) — виджет лишь
встраивает этот инструмент в интерфейс amoCRM.

## Как работает сверка (гибрид)

1. **Префильтр в браузере** (бесплатно, мгновенно): perceptual hash + сравнение
   пикселей. Если картинки идентичны → ответ «Совпадают» без обращения к ИИ.
2. **ИИ‑сверка** (при различиях): обе схемы отправляются в недорогую vision‑модель
   через OpenRouter, которая сравнивает планировку по смыслу (комнаты, стены,
   проёмы), игнорируя масштаб/поворот/оформление, и перечисляет расхождения.
   Стоимость одного сравнения — доли копейки.

## Установка

### 1. Разверните приложение (бэкенд + страница `/bti`)

Приложение уже настроено под Vercel. Задайте переменные окружения (см.
`.env.example` в корне репозитория), как минимум:

```
OPENROUTER_API_KEY=sk-or-...           # ключ OpenRouter
OPENROUTER_MODEL=google/gemini-2.5-flash-lite   # или qwen/qwen-2.5-vl-7b-instruct
BTI_API_TOKEN=любая-длинная-строка     # необязательно, но рекомендуется
BTI_PUBLIC_URL=https://ваш-проект.vercel.app
```

После деплоя инструмент доступен по адресу
`https://ваш-проект.vercel.app/#/bti` — можно открыть и проверить вручную.

### 2. Соберите пакет виджета

Сначала сгенерируйте иконки (или положите свои `images/logo.png` 168×168 и
`images/logo_min.png` 32×32):

```
python3 amocrm-widget/images/generate-icons.py
```

Затем упакуйте архив:

```
cd amocrm-widget
zip -r ../bti-widget.zip manifest.json script.js i18n images
```

В архиве должны лежать `manifest.json`, `script.js`, папки `i18n/` и `images/`
(без вложенной папки верхнего уровня).

### 3. Загрузите в amoCRM

amoCRM → **Настройки → Интеграции → Создать интеграцию → Загрузить виджет** →
выберите `bti-widget.zip`. После установки откройте настройки виджета и укажите:

- **Адрес приложения** — `https://ваш-проект.vercel.app`
- **Токен доступа** — то же значение, что в `BTI_API_TOKEN` (если задавали)

## Где появляется инструмент

- **Страница настроек виджета** — инструмент встроен прямо там (гарантированно
  работает). Менеджер открывает виджет и сразу загружает две схемы.
- **Карточка сделки/контакта** — кнопка «Открыть сверку планов БТИ» открывает
  инструмент в модальном окне.

> Расположение кнопки на карточке зависит от темы amoCRM. Если кнопка не
> появилась, используйте встроенный инструмент на странице настроек виджета —
> вся логика сверки одинаковая. Селектор для карточки в `script.js`
> (`callbacks.render`) при необходимости легко поправить под ваш интерфейс.

## Безопасность

- Ключ OpenRouter хранится только на сервере, в браузер не попадает.
- `BTI_API_TOKEN` (заголовок `x-bti-token`) ограничивает доступ к
  `/api/bti/compare`, чтобы эндпоинтом не пользовались посторонние.

## Иконки

Иконки‑заглушки создаются скриптом `images/generate-icons.py` (см. шаг 2).
Замените `images/logo.png` (168×168) и `images/logo_min.png` (32×32) на ваш
логотип, сохранив имена и размеры.
